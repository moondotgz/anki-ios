Install

  1. Install SideStore or AltStore on your device.
  2. Tap Add to SideStore or Add to AltStore above on your iPhone or iPad, or add the source URL by hand.
  3. Open the source and install AnkiSwift. Updates show up in the app's Updates tab.

Requires iOS 26 or later. Each build is also available as an unsigned IPA on the releases page.

Features

  • Two-way sync with AnkiWeb or a self-hosted Anki sync server, including media
  • Anki's v3 SM-2 scheduler: learning steps, fuzz, leeches, burying and daily limits
  • Anki templates: cloze, type-in answers, hints, furigana, audio, images and night mode
  • Import .apkg decks (including AnkiWeb shared decks) and .colpkg backups, export .apkg
  • Note editor, card browser with Anki search syntax, deck options and statistics
